# Demo tour photos

Seed photos for the fictional demo catalog. The demo seeder uploads them through the normal photo pipeline
(validation, re-encoding to WebP, metadata stripped), so they behave exactly like photos an agency uploads.

All photos are from Unsplash and used under the [Unsplash License](https://unsplash.com/license), which allows free
use without attribution. Photographers' names are left out because this public repository keeps no real names;
each link below identifies the original photo. Files were resized to at most 1920 px and re-compressed.
